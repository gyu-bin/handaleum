개인정보 처리방침

시행일: 2026년 7월 27일

한달음(이하 “앱”)은 한 달의 사진을 지도 위에 펼쳐 회고할 수 있도록 돕는 iOS 앱입니다. 본 방침은 앱이 어떤 정보를 다루는지 설명합니다.

1. 수집·이용하는 정보

  • 사진 라이브러리 — 사용자가 허용한 범위의 사진에 대해, 표시·회고를 위해 촬영 시각과(있을 경우) 위치 좌표를 읽습니다. 원본 사진 파일은 앱 서버로 업로드하지 않으며, 기기 내 참조로 표시합니다.
  • 위치 — 사진에 포함된 위치 메타데이터를 지도 표시에 사용합니다. “집 위치” 기능을 쓰면, 사용자가 지정한 좌표·반경을 기기에 저장해 집 근처 사진을 지도에서 제외합니다. 백그라운드 상시 추적은 하지 않습니다.
  • 앱 내 설정·회고 카드 — 선택한 월, 대표 사진, 만든 카드의 제목·코멘트·구성 등은 기기 로컬 저장소에 보관됩니다.

2. 제3자 제공·처리

  • 지도 화면은 네이버 지도 SDK를 통해 표시될 수 있으며, 지도 타일 요청 과정에서 일반적인 네트워크·기기 환경 정보가 SDK·지도 서비스 측에 전달될 수 있습니다.
  • 장소 이름 표시를 위해 기기 OS의 역지오코딩(주소 변환)을 사용할 수 있습니다.
  • 앱은 광고 SDK로 사진·개인 위치를 판매하거나, 분석 목적으로 사진 원본을 외부에 전송하지 않습니다.

3. 보관

사진 원본은 사용자의 사진 앱에 남습니다. 앱이 만든 설정·카드 데이터는 앱 삭제 시 함께 제거되는 것을 원칙으로 합니다.

4. 권한

사진·(필요 시) 위치 권한은 OS 설정에서 언제든 변경·철회할 수 있습니다. 권한을 끄면 해당 기능이 제한됩니다.

5. 아동

앱은 아동을 대상으로 한 서비스를 의도하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

6. 문의

개인정보 관련 문의는 GitHub Issues로 남겨 주세요.

7. 변경

방침이 바뀌면 이 페이지와 시행일을 갱신합니다.
