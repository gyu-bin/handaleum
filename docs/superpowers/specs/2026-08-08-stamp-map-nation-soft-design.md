# 발도장 방문 지도 — 전국 완화 (옵션 2)

상태: 승인 (사용자 2026-08-08)

## 목표

전국 뷰가 “시·도를 다 찍은 것처럼” 보이지 않게 한다. 확대(L1)는 기존 시군구 grain 유지.

## 결정

| 레이어 | 동작 |
|--------|------|
| 전국 | 전 시·도 윤곽 유지. 방문 시·도만 **옅은 wash** (점 없음). |
| 확대 | 방문 L1(시/군/구)만 칠함 — 변경 없음. |
| 탭 | 전국 → 시·도 확대 → L1 선택 — 변경 없음. |

## 비범위

- 동(dong) grain 지도 채색
- 전국에서 미방문 시·도 숨기기
