# 발도장 방문 지도 — 하이브리드 동 격자 (옵션 3)

상태: 폐기 (2026-08-08 — glance dots 스펙으로 대체)

선행: `2026-08-08-stamp-map-nation-soft-design.md` (전국 = 방문 L1 패치만)

## 목표

지도는 L1까지 가볍게 두고, 동 디테일은 **폴리곤 칠이 아니라 격자/도장 칩**으로 본다.

## 흐름

| 단계 | UI | 탭 |
|------|-----|-----|
| 1 전국 | 시·도 윤곽 + 방문 L1 패치 | 시·도 → 확대 |
| 2 시·도 | L1(구·시·군) 칠 | L1 → 동 격자 (지도 숨김) |
| 3 동 격자 | StampBadge 3열, 방문분 강조 | 방문 동 → 기존 사진 모달 |

뒤로: 동 격자 → 시·도 지도 → 전국. 닫기 시 단계 리셋.

## 내비 연동

L1 진입 시 `onSelect({ sido, l1Key })`로 StampScreen도 같은 L1에 맞춤 (모달은 닫지 않음).

## 비범위

- 동 폴리곤 지도 채색
- 미방문 동 사진 모달
- 시트/바텀시트 변형 (풀스크린 격자만)
