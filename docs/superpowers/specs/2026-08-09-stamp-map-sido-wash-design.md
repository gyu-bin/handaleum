# 발도장 방문 지도 — 시·도 wash + 라벨 + 범례 (옵션 2)

상태: 승인 (사용자 2026-08-09, 참조 목업 첨부)

선행: glance-dots — **점은 유지**, 영역 wash·라벨·범례 추가.

## 목표

첨부 목업에 가깝게:
- 방문 시·도만 **파스텔 wash** (권역별 고정 팔레트)
- **전국 시·도 라벨** (안 간 곳도 이름)
- 방문 동 **검정 점**
- 하단 **권역 범례** (색점 + 이름 + 동 N)
- 헤더 X 닫기, 종이 배경

## 팔레트 (권역)

| 권역 | 시·도 | wash |
|------|-------|------|
| 서울·경기 | 서울, 인천, 경기 | mint |
| 강원 | 강원 | coral |
| 충청 | 충북, 충남, 대전, 세종 | sand (방문 시만) |
| 전라 | 전북, 전남, 광주 | olive |
| 경상 | 경북, 경남, 부산, 대구, 울산 | blue |
| 제주 | 제주 | amber |

미방문 시·도: landLight (칠 없음에 가깝게).

## 한계 (솔직히)

목업의 수채 번짐·종이 질감은 비트맵 일러스트. 앱은 SVG flat fill + PaperGrain으로 **구성·색·라벨·범례**를 맞춤. 픽셀 단위 수채 복제는 하지 않음.
