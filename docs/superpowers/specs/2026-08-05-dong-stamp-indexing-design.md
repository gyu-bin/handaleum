# 발자취형 동 단위 + 인덱싱 UX (2026-08-05)

## 확정
- Grain = **법정동만** (읍·면·리·시군구 도장 없음)
- 발도장 내비 = **시·도 → 시 → 동** (방문/미방문 한눈)
- 방문 지도 = 동 단위 색칠
- 홈(지도) 상단 = 인덱싱 진행 배너 (장수·단계)
- 온보딩 = 발자취식 한 장 (P3)
- 실시간 위치·알림 권한 = **이번 범위 제외** (앨범 GPS + 사진 권한)
- 기존 시군구 도장 = 재스캔으로 동 키 전환 (구 키 orphan prune)

## 단계
| Phase | 내용 |
|---|---|
| P0 | 홈 상단 진행 배너 + sync 진행률 구독 |
| P1 | 동 인덱스·저장 키·발도장 시→동 UI |
| P2 | 동 경계 geo + 방문 지도 |
| P3 | 온보딩 첫인상 |

## 성공 기준
- [x] 지도 진입 시 sync 중이면 상단에 단계·장수가 보인다
- [x] 완료 후 배너가 사라진다
- [x] 발도장이 시·도→시→동이며 방문/미방문이 구분된다
- [x] 방문 지도가 동 단위로 칠해진다
- [x] 온보딩 한 장 (사진 토글·시작)

## 데이터 가정
- 동 경계/목록 = admdongkor **행정동** 중 이름 `동` 접미 (읍·면·군 제외)
- 사진 geocode의 법정동과 1:1이 아닐 수 있음 → `matchIndexedDong`로 완화
